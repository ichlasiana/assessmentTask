Here's the way to open my automation test:

1. I'm using Java 8.1 for this automation test
2. I recommend to use IntelliJ IDE
4. Please make a new folder called "driver" that contain chromedriver, Please make sure the chromedriver version exactly same as your chrome version. You can download it here https://sites.google.com/chromium.org/driver/downloads
4. In IntelliJ, please go to pom.xml and click "refresh maven" button. Please wait until all the dependencies downloaded
5. please install Cucumber, Gherkin in plugin section
6. After all dependencies and plugin successfully installed, go to the left corner and click Maven logo
7. Run 'mvn clean'
8. Run 'mvn test'

Thank you!
